# CH347 传感器驱动切换说明

项目中有两套 CH347 USB-I2C 传感器驱动实现，通过不同方式读取 LSM6DS3 系列 IMU 数据。

## 两种实现概览

| 项目 | ubuntu347t.cc | ch347t.cc |
|------|-------------|-----------|
| 进程名 | `ubuntu347t` | `sensord_ch347` (ch347t) |
| 驱动方式 | Linux 原生 `/dev/i2c-N` | libch347.so 用户空间库 + 原生 I2C 回退 |
| 所需驱动脚本 | `install_ch347_vcp.sh` | `install_ch347.sh` |
| 内核模块 | mfd-ch347.ko + i2c-ch347.ko | ch34x_pis.ko |
| 用户空间库 | 无 | libch347.so |
| 特性 | 启动 IMU 装偏校准、冻结检测、USB rebind 恢复 | 双后端自动切换（CH347 优先，原生 I2C 回退，后台自动升级） |

**当前默认使用**: `ch347t.cc` (sensord_ch347)，定义在 `system/manager/process_config.py:111`

## 切换方式

### 方式一：通过进程切换（修改 process_config.py）

这是**主要切换方式**，通过修改进程管理器配置文件来启用/禁用对应的进程。

编辑 `system/manager/process_config.py`，修改第 111-112 行：

**切换到 ubuntu347t**（纯原生 I2C / AYSTARIK 驱动）：
```python
# NativeProcess("sensord_ch347", "system/sensord", ["./ch347t"], always_run, enabled=PC, watchdog_max_dt=3),
NativeProcess("ubuntu347t", "system/sensord", ["./ubuntu347t"], always_run, enabled=PC, watchdog_max_dt=3),
```

**切换到 ch347t**（libch347.so 用户空间库）：
```python
NativeProcess("sensord_ch347", "system/sensord", ["./ch347t"], always_run, enabled=PC, watchdog_max_dt=3),
# NativeProcess("ubuntu347t", "system/sensord", ["./ubuntu347t"], always_run, enabled=PC, watchdog_max_dt=3),
```

修改后重启 openpilot 或执行 `./restart.sh` 使配置生效。

> **注意**：两个进程同时只能启用一个，否则会冲突。

### 方式二：执行对应的 .sh 脚本安装驱动

**必须执行**。两套代码依赖不同的底层驱动，切换前需要先安装对应的驱动。

#### 使用 ubuntu347t.cc 时

需要 AYSTARIK 内核 I2C 子系统驱动：

```bash
sudo bash install_ch347_vcp.sh
```

此脚本会：
- 编译安装 `mfd-ch347.ko` + `i2c-ch347.ko` 内核模块
- 配置 udev 规则自动加载驱动
- 设备以标准 `/dev/i2c-*` 形式呈现
- **同时会卸载旧版 `ch34x_pis.ko` 和 `libch347.so`**

#### 使用 ch347t.cc 时

需要原厂 ch34x_pis 内核模块 + libch347.so 用户空间库：

```bash
sudo bash install_ch347.sh
```

此脚本会：
- 编译安装 `ch34x_pis.ko` 内核模块
- 安装 `libch347.so` 到 `/usr/local/lib/`
- 配置 udev 规则自动加载驱动
- 设备以 `/dev/ch34x_pis*` 形式呈现

## 完整切换步骤

1. **安装对应驱动**（二选一）：
   - 切到 ubuntu347t: `sudo bash install_ch347_vcp.sh`
   - 切到 ch347t: `sudo bash install_ch347.sh`

2. **启用编译**（仅切换到 ubuntu347t 时需要）：编辑 `system/sensord/SConscript`，取消注释编译条目
   ```python
   # 默认已注释，使用时取消注释
   env.Program('ubuntu347t', 'ubuntu347t.cc', LIBS=libs)
   ```

3. **修改进程配置**：编辑 `system/manager/process_config.py` 启用目标进程、禁用另一个

4. **重启系统**：`./restart.sh`

5. **验证**：检查进程是否正常运行
   ```bash
   # ubuntu347t 模式下
   ls /dev/i2c-* && lsmod | grep ch347
   # ch347t 模式下
   ls /dev/ch34x_pis* && lsmod | grep ch34x_pis
   ```

## 注意事项

- 两套驱动**互斥**，不能同时安装。`install_ch347_vcp.sh` 会清理旧的 `ch34x_pis` 和 `libch347.so`。
- 内核升级后需要重新运行对应的安装脚本重新编译内核模块。
- `ubuntu347t.cc` 的编译条目在 `SConscript` 中默认注释，切换到该驱动时需要取消注释。
